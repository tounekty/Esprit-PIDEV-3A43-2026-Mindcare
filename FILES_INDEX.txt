⚡ COMMANDES RAPIDES
═══════════════════════════════════════════════════════════════

Lancer le serveur:
$ php bin/console server:run
ou
$ symfony server:start

Vérifier les routes:
$ php bin/console debug:router

Nettoyer le cache:
$ php bin/console cache:clear

Générer les assets:
$ php bin/console assets:install

═══════════════════════════════════════════════════════════════
🎓 POINTS CLÉS À RETENIR
═══════════════════════════════════════════════════════════════

1. Les templates héritent de base_front.html.twig ou base_admin.html.twig
2. Les assets doivent être dans public/front_assets/ ou public/admin_assets/
3. Utilisez {{ asset() }} pour les chemins d'assets
4. Utilisez {{ path() }} pour les URLs des routes
5. L'admin est protégé par #[IsGranted('ROLE_ADMIN')]
6. Toutes les routes sont automatiquement enregistrées
7. Bootstrap 5 est inclus par défaut
8. Les images vont dans public/.../img/ ou public/.../images/
9. Consultez les documentations pour plus d'infos
10. Le support communautaire Symfony est excellent
