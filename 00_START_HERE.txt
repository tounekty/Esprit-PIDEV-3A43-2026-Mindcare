┌───────────────────────────────────────────────────────────────┐
│              🎓 10 POINTS CLÉS À RETENIR                       │
└───────────────────────────────────────────────────────────────┘

1️⃣  Les templates héritent de base_front ou base_admin
2️⃣  Les assets doivent être copiés manuellement
3️⃣  Utilisez {{ asset() }} pour les chemins
4️⃣  Utilisez {{ path() }} pour les routes
5️⃣  L'admin est protégé par #[IsGranted('ROLE_ADMIN')]
6️⃣  Les routes sont automatiquement enregistrées
7️⃣  Bootstrap 5 est inclus par défaut
8️⃣  La sécurité est basée sur les rôles
9️⃣  Consultez les documentations en cas de doute
🔟  Le support communautaire Symfony est excellent
