⚠️ EN CAS DE PROBLÈME
═══════════════════════════════════════════════════════════════

Erreur: Les routes retournent 404
→ Vérifiez que le serveur tourne
→ Vérifiez les namespaces dans les contrôleurs
→ Exécutez: php bin/console debug:router

Erreur: Les images ne s'affichent pas
→ Vérifiez que copy_assets.bat a été exécuté
→ Vérifiez les dossiers public/front_assets/ et public/admin_assets/
→ Vérifiez les chemins dans les templates

Erreur: CSS/JS ne s'appliquent pas
→ Videz le cache navigateur (Ctrl+Shift+Del)
→ Vérifiez que les fichiers existent
→ Vérifiez que {{ asset() }} est utilisé

Erreur: Accès admin bloqué
→ Vérifiez que vous êtes connecté
→ Vérifiez que l'utilisateur a ROLE_ADMIN
→ Vérifiez la configuration security.yaml
